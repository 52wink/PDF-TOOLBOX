# PDF 工具箱（Soft Pastel 奶油风）

> 纯离线 · 零上传 · 全免费 · 开源 —— 一个 HTML 文件搞定 35 项 PDF 操作

一个单文件、纯浏览器端运行的 PDF 工具箱：所有处理都在本地完成，文件不会上传到任何服务器，**保存网页后断网也能用**，适用于 Windows / macOS / Linux / 国产信创 / 安卓 / iOS，有浏览器就能用。

本项目基于 [wallechfox/offline-pdf-tools](https://github.com/wallechfox/offline-pdf-tools) 改写，保留并继承上游的全部 35 项功能与 PDF 处理能力，在此对原作者表示感谢。

## ✨ 本项目改进

- **页面风格**：重做为 Soft Pastel 奶油治愈风（奶油纸底 + 粉紫蓝柔光 + 圆角卡片 + 渐变胶囊按钮），支持浅色 / 深色模式，并跟随宿主页面主题自动切换；卡片两列布局、左对齐、标题单行省略、简介两端对齐
- **页面逻辑**：顶部导航简化、返回面板逻辑重构，避免宿主页面样式干扰；适配 Lenis 平滑滚动等常见站点环境
- **交互增强**：单文件工具增加「🗑 删除文件/图片」按钮，点击返回时自动清空已上传文件；多文件工具保留清空列表
- **大图预览**：修复原版大图无法显示的 bug，并新增放大 / 缩小按钮（20%–500%）与比例显示，切换页面自动重置

## 🧰 功能清单（5 大类 35 项）

### 📄 页面管理（9）
常规合并、交替合并、常规拆分、按书签拆分、按书签炸开、页面重排、页面倒序、补齐空白页、删除页面

### 📐 页面调整（8）
页面旋转（批量）、页面旋转（逐页）、页面拼版、统一页面大小、拆分对开页、倾斜校正、裁剪白边、生成空白 PDF

### 🖼️ 格式与图像处理（7）
PDF 转图片、图片转 PDF、PDF 扁平化、提取图片、页面滤镜、工程蓝图、模拟扫描件

### 🏷️ 标注与编号（7）
添加页码、Bates 编页、文字水印、图片水印、添加图章、扇形骑缝章、批注

### 🔐 安全与信息（4）
文档信息（元数据）、删除书签、PDF 压缩、PDF 解密

## 🚀 使用方法

1. 下载 `PDF工具箱-35项功能-奶油风版.html`（仓库根目录的 HTML 文件）
2. 双击用浏览器打开即可使用；也可部署到任意静态站点 / GitHub Pages
无需安装、无需联网、无需注册，文件不出本机。

## ⚙️ 技术说明

- 单文件 HTML，内置所有依赖，离线可用
- PDF 解析与渲染：[pdf.js](https://mozilla.github.io/pdf.js/)（Apache-2.0）
- PDF 生成与编辑：[PDF-Lib](https://pdf-lib.js.org/)（MIT）
- 压缩打包：[JSZip](https://stuk.github.io/jszip/)（MIT / GPL-3.0）
- 无后端、无第三方请求，所有计算均在浏览器本地完成
